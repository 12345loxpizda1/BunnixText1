# BunnixText

Telegram-бот: меню стран (17 кнопок) → по нажатию присылает случайную фразу
(бонус + фри спины) на языке страны, через 2 минуты сообщение удаляется.

## Запуск

```
python bot.py
```

## Переменные окружения

| Переменная   | Обязательна | Что это                                          |
|--------------|-------------|--------------------------------------------------|
| `BOT_TOKEN`  | да          | Токен бота от @BotFather                         |
| `BONUS_LINK` | нет         | Ссылка оператора; добавляется под фразу. Пусто — фраза без ссылки |

## Файлы

- `bot.py` — сам бот (только стандартная библиотека Python)
- `phrases.json` — заготовки: 17 стран × 500 фраз
- `requirements.txt` — зависимостей нет (stdlib only)

## Render

1. Service → Settings → **Start Command**: `python bot.py`
2. Service → Environment: добавить `BOT_TOKEN` и (опционально) `BONUS_LINK`
3. Manual Deploy → Deploy latest commit
